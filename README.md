# aws-highly-available-web-app
⚖️ Production-style 3-tier architecture with Bastion host, NAT, Load Balancer &amp; Auto Scaling.

🏦 AWS QuickLoan Site-Portal is a hands-on, end-to-end AWS deployment of a loan application portal, from a secure custom VPC to Auto Scaling. It runs Nginx and PHP with RDS MySQL on a bastion-protected network and serves images from S3. An ALB and Auto Scaling keep it scalable, and CloudWatch and SNS send monitoring alerts. Includes a complete step-by-step guide. ☁️🚀

🧰 Tools Covered 🛡️☁️ End-to-end AWS loan portal: custom VPC, bastion host, Nginx/PHP, RDS MySQL, S3, ALB, Auto Scaling, CloudWatch & SNS. Complete step-by-step guide.📜
